# VOICE_AND_STYLE.md — Chasing Fun Newsletter

> Read this every weekly run, before touching the user's text.
> If in doubt, leave the sentence alone.

---

## The One Rule

**Don't rewrite Dor. Only clean.**

The voice in the newsletter is Dor Damari speaking in first person. Every sentence must still sound like *him* after the agent is done. If the agent's edit makes a sentence sound smoother but less *him*, the edit is wrong.

---

## What the Agent IS Allowed to Fix

- Spelling mistakes (שגיאות כתיב)
- Punctuation and spacing
- Paragraph breaks where a wall of text needs air
- Obvious grammatical errors that change meaning
- Hebrew typing slips (e.g., final-letter mistakes)

## What the Agent is NOT Allowed to Touch

- Sentence length (Dor writes long when he writes long, short when he writes short)
- Word choice — even if the agent thinks a synonym is better
- Order of ideas
- Adding "marketing polish" anywhere
- Removing personal asides, parenthetical thoughts, or apparent "tangents" — these are part of the voice
- Adding emojis Dor didn't add
- Translating Hebrew/English code-switching ("lineup", "סופ״ש", "set", "פיק") — keep it as-is

If the agent has improvement ideas, they go under a separate section labeled **"הצעות לשיפור — לא הוטמעו עדיין"**.

---

## How Dor's Voice Sounds (Operational Markers)

- **First person, casual.** Not "we believe..." — "אני חושב ש..." / "אני יודע ש..."
- **Sea as metaphor for life** is constant — but never explained. Lean into it, don't unpack it.
- **Mixes Hebrew with English surf vocabulary** — that's the actual culture. Don't normalize.
- **Talks to ONE person**, not a list. "אם אתה תוהה..." not "אם אתם תוהים...".
- **Uses "סופ״ש"** (with gershayim), not "סופש" or "סוף שבוע".
- **Doesn't moralize.** Observations, not lessons.
- **Short paragraphs in mobile.** Even if Dor writes long — break into 2-3 sentence paragraphs for readability. (This is layout, not rewriting.)

---

## Things That Should Never Appear

- Words like *"רגע, חברים"*, *"בואו נדבר על..."*, *"היום אני רוצה לשתף איתכם..."* — these are radio-host openers, not Dor.
- Generic surf clichés ("הים תמיד צודק", "תזרום עם הגל", "מי שלא נופל לא לומד") unless Dor wrote them himself, in which case they stay.
- Any phrase that could appear in a corporate wellness newsletter.
- Excessive hashtags or emojis. One emoji per post is plenty (and only if Dor used one).
- "Engagement bait" questions at the end ("ספרו לי בתגובות מה אתם חושבים").

---

## The 30-Second Voice Test

Before approving any draft, the agent asks itself:

> *"If Dor's mom or his closest 5 surf friends read this without seeing the URL, would they say 'this is exactly how Dor talks'?"*

If the answer is "kind of" or "close enough" → the edit went too far. Revert.
If the answer is "yes, that's him" → ship it.

---

## Inputs That Override This File

If Dor explicitly says in his weekly input *"clean this up more aggressively"* or *"feel free to tighten"* — only then can the agent take liberties. Default behavior is always conservative.
