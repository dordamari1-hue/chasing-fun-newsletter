# weekly-performance-template.md

> One row per published post. Append-only. The agent updates this every weekly run.

---

## Schema

| # | Date | Topic (short) | Live URL | Community Link | Views | Median Time | CTA Clicks | Notes |
|---|------|---------------|----------|----------------|-------|-------------|-----------|-------|

Where:
- `#` — campaign number, e.g. `5`
- `Date` — Friday publish date, `YYYY-MM-DD`
- `Topic` — 3-5 word teaser
- `Live URL` — bare URL, no UTM
- `Community Link` — UTM-tagged WhatsApp link
- `Views` — unique page views (filled in Sunday review)
- `Median Time` — median time on page in seconds (filled Sunday)
- `CTA Clicks` — clicks per CTA, format: `newsletter:N | whatsapp:N | trip:N`
- `Notes` — anything noteworthy for the week (event, image performance, A/B test result)

## Monthly Rollup (auto-generated end of month)

> The agent computes:
> - Total views for the month
> - Avg median time
> - Best-performing post (by median time × views)
> - Worst-performing post (for honest learning, not blame)
> - Top traffic source
> - Recommendations for next month (max 3, never auto-applied)
